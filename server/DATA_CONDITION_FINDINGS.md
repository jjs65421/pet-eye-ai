# 유루증·안검염 데이터 구성 점검

## 확인한 근거

확정 라벨 목록 전체의 촬영 장비·품종·동물 종류 구성을 집계했습니다. 두 질환의 일반카메라 양성 사진에서 학습/검증/평가별 100장씩, 총 600장의 원본 JSON을 추가 대조했습니다. 사진과 라벨 원본은 수정하지 않았습니다.

| 구성 | 유루증 | 안검염 |
|---|---:|---:|
| 일반카메라 학습 사진 | 2,341장 | 1,098장 |
| 위 사진 중 고양이 | 0장 | 143장 |
| 일반카메라 검증 사진 | 419장 | 210장 |
| 일반카메라 평가 사진 | 1,076장 | 138장 |
| 스마트폰 양성 학습 사진 | 3,222장 | 0장 |

안검염 평가 138장은 포메라니안 62장, 말티즈 76장으로만 구성됩니다. 학습 자료에는 다른 개 품종과 고양이가 섞여 있습니다. 유루증 평가 자료는 포메라니안 598장이 가장 많습니다. 두 질환의 학습·검증·평가에서 품종 구성이 동일하지 않습니다.

### 품종별 오분류

현재 모델은 유루증 푸들 165장 중 14장(8.5%)만 유루증으로 맞혔고, 나머지 151장을 안검염으로 분류했습니다. 반면 말티즈 유루증은 189장 중 144장(76.2%)을 맞혔습니다. 안검염은 포메라니안 62장 중 56장(90.3%), 말티즈 76장 중 28장(36.8%)을 맞혔습니다. 품종에 따른 큰 성능 차이는 확인되지만, 그 원인이 품종 특징 자체인지 촬영기관·질환 중증도 등 다른 조건인지 이 자료만으로 확정할 수 없습니다.

### 동물 종류와 평가 수치

전체 5분류 평가 자료 2,037장에서 고양이 131장은 모두 결막염입니다. 현재 모델의 고양이 평가 정답률은 98.5%, 개 평가 정답률은 52.8%입니다. 다른 고양이 질환을 구별하는 능력은 이 평가에서 측정하지 못합니다. 결막염의 전체 정답률 77.5% 중 개 사진 140장만 보면 57.9%입니다. 따라서 전체 결막염 성능을 모든 동물에 일반화할 수 없습니다.

### 라벨과 공존 질환

- 원본 JSON의 질환명·최종 라벨이 학습 목록과 일치함을 표본 600장에서 확인했습니다.
- 최초/최종 판독 불일치는 유루증 학습 2/100, 검증 1/100; 안검염 학습 12/100, 검증 13/100입니다. 두 질환의 평가 표본에서는 불일치가 없었습니다. 현재 학습은 이미 최종 판독을 사용하므로 최초 라벨로 되돌리지 않았습니다.
- 같은 원본 파일명에 두 질환이 모두 양성으로 표기된 기록은 전체 목록에서 0건입니다. JSON은 해당 사진의 질환 하나를 기록합니다. 이 결과는 공존 질환이 없다는 증거가 아닙니다. 개체 식별자와 다른 질환의 동시 판독이 없어 공존 여부를 확정할 수 없습니다.
- 사진을 보고 의료 라벨을 임의 변경하지 않았습니다.

### 촬영 조건 표본

두 질환 평가 표본의 촬영 시기는 모두 2021년 8~9월입니다. 학습 표본은 더 넓은 시기를 포함합니다. 유루증 평가 표본 나이 중앙값은 5세, 안검염은 5세입니다. 원본 크기 대비 라벨 사각형 면적 중앙값은 두 질환과 모든 분할에서 약 34~36%로 비슷했습니다. 해당 표본에서는 사각형 크기의 큰 차이를 혼동 원인으로 확인하지 못했습니다. 실제 조명·구도·촬영기관 차이가 없다는 뜻은 아닙니다.

## 근거에 따른 학습 실험

5개 질환에 모두 있는 개 사진만으로 학습/검증하고, 학습에서 품종별 표본 수의 역제곱근 가중치를 적용했습니다. 희귀 품종이 지배하지 않도록 가중치를 제한하고 각 질환의 총 가중치를 유지했습니다. 평가 2,037장은 제외하거나 수정하지 않았습니다. 출력층 학습과 추가 학습 후보 선택에는 검증 사진을 사용했습니다.

| 지표 | 기존 서버 | 개·품종 균형 후보 |
|---|---:|---:|
| 전체 정답률 | 55.7% | 61.0% |
| 질환별 정답률 평균 | 56.2% | 55.4% |
| 백내장 | 42.4% | 58.3% |
| 유루증 | 55.9% | 68.3% |
| 핵경화 | 44.5% | 31.7% |
| 안검염 | 60.9% | 45.7% |
| 결막염 | 77.5% | 73.1% |

**균형 정답률과 핵경화·안검염 성능이 악화되어 후보를 적용하지 않았습니다.** 서버는 `differential-20261013-162941`을 유지합니다. 후보는 `differential-20261013-164932`에 저장했습니다. 개 전용 학습 후보는 고양이 분류를 지원한다고 간주할 수 없습니다.

## 결론과 다음 개선

질환 이름이 잘못 연결된 오류는 점검한 표본에서 발견되지 않았습니다. 동물 종류·품종·촬영 시기에 따라 자료 구성이 다르며 품종별 성능 차이가 큽니다. 이를 보정하는 것만으로 5개 질환 성능이 고르게 좋아지지는 않았습니다.

남은 작업은 동물 종류별로 평가를 나누고, 학습 자료에서 동물 종류·품종 조건을 함께 고려한 검증 분할을 만든 뒤 학습 설정을 선택하는 것입니다. 현재 반복 확인한 평가 자료는 개발 평가로만 보고해야 하며, 새 사진의 정확도를 주장하려면 별도 평가 사진이 필요합니다. 유루증/안검염 동시 라벨이나 전문 판독 없이는 공존 질환 문제를 자동으로 해결할 수 없습니다.
