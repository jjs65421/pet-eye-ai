# 최고 점수 참고 결과 표시

현재 활성 모델은 정상 사진 없이 학습한 5분류 모델입니다. 낮은 분류 점수를 정상으로 해석하지 않습니다. 정상 판정 근거로 쓸 5개 질환 모두 음성인 원본 파일명 그룹은 현재 목록에 0개입니다. 사용자는 별도 확인된 정상 자료도 없다고 답했습니다.

현재 표시 규칙 `always_show_top_score_v1`:

- 다섯 질환 점수 중 가장 높은 항목과 점수를 항상 표시합니다. 점수 임계값이나 1·2위 간격으로 결과 표시를 막지 않습니다.
- 너무 어둡거나 밝아 이미지를 처리할 수 없는 입력은 계속 제외합니다.
- 점수는 교정된 신뢰도, 발병 확률 또는 검증된 진단 정확도가 아닙니다. 항상 최고 항목을 보여주는 변경은 오분류나 비안구 사진 오분류를 해결하지 않습니다. 이미지 특징 유사도는 안내용입니다.

## 정상 결과

API와 앱에는 `normal_reference` 표시 분기를 추가했습니다. 실제로 활성화하려면 정상 클래스를 포함해 재학습한 모델의 라벨 순서가 기존 5개 + `정상`이어야 하고, 메타데이터 `confirmed_normal_supported`가 참이어야 합니다. 현재 모델에는 해당 클래스와 근거가 없어 `normal_class_available: false`입니다. 이 표시 분기를 추가한 것만으로 정상 탐지 모델이 학습된 것은 아닙니다.

`needs_visit: false`는 정상 또는 병원 방문 불필요를 뜻하지 않습니다. 판단 어려움 화면은 증상이 있거나 걱정되면 수의사 상담을 권유합니다. 정상 참고 화면도 확정 정상으로 안내하지 않습니다.

서버의 표시 정책을 바꿨습니다. 기존 기록은 당시 저장된 결과를 보존합니다. 모델을 재학습하거나 새 정확도를 산출한 변경이 아닙니다.
