# 5개 질환 공동 학습 (현재 실험 모델)

하나의 모델에서 다섯 점수를 내고 최고 점수 하나를 강제로 표시합니다. 정상 사진도 하나로 분류됩니다.

학습 5,130장, 검증 1,003장, 평가 2,037장. 전체 정답률 55.7%, 균형 정답률 56.2%, macro F1 51.2%. 개발 품질 기준은 미통과이며 요청에 따라 실험용으로 적용했습니다. 스마트폰 정확도는 미확인입니다.

# 백내장 편중 문제 확인과 비교 모델

현재 사용자 출력은 다섯 모델 점수 중 가장 큰 항목 하나와 0~100점 점수입니다. 유루증도 최고 점수 선택에 포함합니다. API의 `prediction.disease`와 `prediction.score_points`를 사용하며, 앱에서는 전체 점수 목록을 표시하지 않습니다. 이는 서로 산출 기준이 다른 모델의 숫자상 최댓값으로, 실제 질환 가능성 순위나 확률로 검증된 값은 아닙니다.

학습 사진의 평균 특징과 유사도가 낮다는 이유만으로 재촬영을 요구하던 검사는 안내로 바꿨습니다. 유사도 평균값은 검증된 눈 사진 판별기가 아니며 다른 촬영 방식의 눈 사진도 거절할 수 있었기 때문입니다. 너무 어둡거나 밝은 사진, 읽을 수 없는 파일에 대한 처리는 유지합니다.

기존 이진 모델은 질환마다 정상/이상 사진을 비교했습니다. 이 모델들의 출력 중 가장 큰 값을 선택하는 것으로는 질환끼리의 구분을 학습할 수 없습니다. 정상 사진과 질환 사진의 촬영 장비가 서로 다른 문제도 있었습니다. 정규화 복원 오류와 라벨 선택을 수정한 후에도 이 방식의 백내장 편중이 남아 있음을 실제 서버 요청에서 확인했습니다. 판정 보류나 참고 점수 표시로 바꾸는 것만으로 이 문제를 해결했다고 할 수 없습니다.

## 변경한 학습

유루증의 기존 선별 모델은 유지했습니다. 나머지 네 질환은 확정 라벨이 양성인 사진으로 하나의 4분류 모델을 학습했습니다. 네 질환을 함께 비교하므로 독립된 이진 모델의 점수 척도를 서로 비교하는 방식은 사용하지 않습니다.

ImageNet EfficientNet의 고정 특징으로 학습한 첫 모델과 검안경·일반카메라를 섞어 추가 학습한 모델은 개발 평가 기준을 통과하지 않아 적용하지 않았습니다. 검안경 사진에서 특히 안검염/결막염 구분이 나빴습니다. 일반카메라 사진으로 범위를 좁힌 모델을 추가 학습해 참고용 비교 모델로 적용했습니다.

새 모델의 질환별 정답률은 백내장 53.9%, 핵경화 43.4%, 안검염 100%, 결막염 71.6%였습니다. 사진·동물·촬영 환경의 편향이 있을 수 있으므로 안검염 100%를 실제 사용 정확도로 해석할 수 없습니다. 백내장과 핵경화의 혼동이 많이 남아 있습니다.

이 평가 자료는 개발 중 여러 모델을 비교하는 데 사용했습니다. 외부 검증이나 독립적인 임상 성능 증거가 아닙니다. 스마트폰의 네 질환 양성 사진은 없어서 스마트폰 질환 판별 정확도도 검증하지 못했습니다. 백내장으로만 쏠리던 현상을 줄인 것과 정확한 진단이 가능한 것은 다른 문제입니다.

## 현재 응답

`prediction.disease`와 `prediction.score_points`에 다섯 모델 중 최고 점수 항목 하나와 점수가 있습니다. `top_finding`과 `findings`에도 동일한 항목 하나만 있습니다. low/high 값은 내부 계산에만 사용합니다. 위 평가 표는 네 질환 비교 모델 자체에 대한 결과이며, 유루증 점수를 함께 비교하는 현재 최댓값 선택 방식의 정확도를 검증한 수치가 아닙니다.

새 모델은 정상/알 수 없는 질환 클래스를 포함하지 않습니다. 정상 사진이나 유루증 사진에서도 네 질환 중 하나를 선택할 수 있으므로 결과는 실제 발병 여부 또는 실제 질환 확률을 뜻하지 않습니다. 앱에서도 모델 분류 점수와 참고 결과로 표시합니다.

`/health`의 `four_disease_method`가 `joint_classification`이고 `classification_model_version`이 있으면 새 비교 모델이 적용된 상태입니다. 학습 파일은 `train_differential.py`와 `finetune_differential.py`, 모델 결과와 혼동행렬은 `models/active_differential.json`이 가리키는 폴더에 저장됩니다. 기존 모델과 실패한 실험 결과는 보존했습니다.
