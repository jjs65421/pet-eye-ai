# 5개 질환 모델 개선 실험

같은 일반카메라 질환 양성 사진 2,037장으로 비교했습니다. 평가 사진은 이전 개발에서 이미 확인한 자료이므로 독립적인 외부 검증이 아닙니다. 스마트폰 성능으로 해석할 수 없습니다.

|---|---:|---:|---:|

## 진행한 작업

- 기존 오분류 20장(질환당 4장)의 사진, 원본 JSON 질환명 및 최종 라벨을 대조했습니다. 모두 현재 학습 목록과 일치했습니다. 육안 점검으로 라벨의 의학적 정확성을 확정할 수는 없습니다. 라벨 변경이나 평가 사진 제외는 하지 않았습니다.
- 같은 일반카메라 조건에서 사용 가능한 학습 사진 전체 5,471장을 사용했습니다. 기존 모델은 유루증 표본 상한 때문에 5,130장을 사용했습니다.
- 특징 추출 부분을 고정한 뒤 새로운 5분류 출력층을 먼저 학습했습니다. 검증 손실을 기준으로 조기 종료했습니다.
- 이어 마지막 35개 층을 낮은 학습률 0.00001로 조정했습니다. BatchNormalization은 고정했고 작은 회전, 명암 변화, 좌우 반전을 적용했습니다.
- 첫 실행의 추가 학습에서 사진 순서를 섞지 않아 검증 성능이 떨어졌습니다. 이를 수정한 두 번째 실행에서는 사진을 섞어 학습했습니다.
- 출력층 단계와 추가 학습 단계 선택에는 검증 사진만 사용했습니다. 최종 평가 결과는 그대로 기록했습니다.
- 저장/복원 모델의 점수가 일치하는지도 확인했습니다.

## 적용 결정

전체 정답률 상승은 평가 자료에서 수가 많은 유루증의 개선 영향이 큽니다(1,076/2,037장). 질환별 평균 정답률은 개선되지 않았고 안검염 정답률이 크게 떨어졌습니다. 전체 정답률, 균형 정답률, Macro F1이 모두 개선되는 후보만 자동 적용하도록 정했으며 두 후보는 이 기준을 통과하지 못했습니다. **서버는 기존 모델을 유지합니다.**

현재 서버: `differential-20261013-162941`

후보: `differential-20261013-164200`, `differential-20261013-164435`

재학습 코드: `improve_joint.py`. 모델 폴더의 `classifier.json`, `test-predictions.npz`에 상세 수치와 같은 사진의 이전/새 점수가 있습니다. `training_data/errors-before.json`과 `errors-before.jpg`에 원본 라벨 대조 및 사진 점검 자료가 있습니다.

다음 작업은 유루증/안검염의 공존 여부와 라벨 범위 확인, 학습/검증의 촬영·품종·질환 단계 차이 분석입니다. 단일 질환 라벨의 한계나 사진에서 구별되지 않는 특징은 학습 횟수를 늘리는 것만으로 해결할 수 없습니다.
